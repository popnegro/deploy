# SmartWeb — Selected Digital Products

One-page portfolio editorial para presentar el trabajo seleccionado de `github.com/popnegro` como producto, no como lista de repositorios.

## Stack
- Next.js 15
- React 19
- TypeScript
- CSS editorial sin dependencia de UI externa

## Selección
- SmartWeb
- MuniBrain
- Grupo Comunicarte
- Emilia Sandobar
- SmartBarrio
- Vertical Products

## Ejecutar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
