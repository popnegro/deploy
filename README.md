# Luis Grasso — Digital Product Portfolio

Portfolio personal de Luis Grasso.

Más de 15 años de evolución profesional entre **diseño, comunicación, web, UX/UI, marketing y tecnología**, trabajando con agencias, startups, empresas y proyectos independientes.

Hoy esa experiencia converge en una nueva etapa: **diseñar y construir productos digitales, plataformas y sistemas que resuelven problemas reales.**

## Positioning

**From visual communication to digital products.**

La evolución no es un cambio de profesión, sino una expansión natural de las capacidades adquiridas durante más de 15 años:

```text
Design → Visual Communication → Digital Design → UX/UI → Web → Product → Technology + AI
```

El portfolio presenta el trabajo actual como la consecuencia de esa trayectoria: pensamiento visual, criterio de producto y capacidad técnica para llevar una idea desde el problema inicial hasta una solución digital funcional.

## Approach

```text
01  Discover — Understand the problem.
02  Define   — Establish scope and priorities.
03  Design   — Create the experience and system.
04  Build    — Turn the solution into something functional.
05  Validate — Test, measure and improve.
06  Evolve   — Build on what already works.
```

## Background

La trayectoria profesional comenzó en diseño gráfico y comunicación visual y evolucionó progresivamente hacia diseño digital, web, UX/UI, marketing y construcción de productos.

La experiencia documentada incluye trabajo en agencias, startups y proyectos freelance, con etapas en Ideologik, Voyenbus, Gambler UI y La Proa, evolucionando desde Senior Graphic Designer hacia Visual Designer / UI & UX Designer.

## Philosophy

> No cambié de profesión. La fui llevando más lejos.

El objetivo de este portfolio no es mostrar una lista de tecnologías, sino explicar **cómo una trayectoria de diseño y comunicación evolucionó hacia la creación de productos digitales.**
